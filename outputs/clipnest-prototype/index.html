ClipNest 是一个面向 Windows 的可视化剪贴板工作台。按下快捷键，它从屏幕底部出现，让最近复制的内容随手可取。

Ctrl + Shift + V 打开 · ↑ ↓ 选择 · Enter 粘贴 · Ctrl + P 收藏

设置

ClipNest 的本地体验与隐私控制

通用

控制 ClipNest 如何出现在 Windows 桌面上。

启动与窗口
登录 Windows 时启动启动后驻留在系统托盘，不主动打断工作。
窗口始终置顶打开剪贴板 shelf 时保持在其他窗口上方。
关闭时最小化到托盘点击关闭只收起窗口，后台继续记录剪贴板。
外观
主题自动跟随 Windows 的浅色/深色模式。

剪贴板

选择要记录的内容，以及历史记录的保留方式。

记录内容
自动记录剪贴板复制后自动加入历史；暂停时不会读取新的内容。
保存图像和文件关闭后只保留文本和链接，减少磁盘占用。
历史记录上限达到上限后优先删除未收藏的最旧内容。
200 条　⌄
复制后自动清理首尾空格仅处理纯文本，不改变原始剪贴板。

隐私

剪贴板里可能包含密码、验证码和私人信息，默认提供可控的保护边界。

保护规则
忽略密码管理器窗口检测到 KeePass、1Password 等窗口时不记录内容。
复制后自动清除敏感内容可设置敏感内容在历史中的保留时间。
关闭　⌄
暂停记录快捷键临时停止监听，不删除已有历史。
Ctrl ⇧ X
ClipNest 默认只在本机保存历史，不上传剪贴板内容，也不做主题或标题的 AI 推断。

存储与备份

历史默认保存在本机，你可以把数据放到其他磁盘或备份位置。

本地数据
保存位置C:\Users\你\AppData\Local\ClipNest
历史清理清理未收藏的旧内容，不影响收藏。
备份
导出本地备份导出历史、收藏、分类和设置。
导入备份从 ClipNest 备份文件恢复历史。

快捷键

保持少量核心快捷键，避免和 Windows 或其他应用冲突。

全局快捷键
打开 / 收起 ClipNest从任意应用唤醒底部 shelf。
Ctrl ⇧ V
搜索历史打开 shelf 后直接聚焦搜索框。
Ctrl K
暂停记录在处理密码或验证码时暂时关闭监听。
Ctrl ⇧ X
原型阶段快捷键显示为示意；Windows 原生版本会在这里提供可修改和冲突检测。
