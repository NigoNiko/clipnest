ClipNest Version 1.22

- Added an About page with the version, GitHub link, and Check for updates button.
- Shows release notes before updating and verifies the installer with GitHub's SHA-256 digest.
- Installs an update in the existing application directory and cleans up downloaded installers.
- Supports private repository updates with a per-user, Windows-encrypted read-only GitHub token. Public releases can be checked without a token.
