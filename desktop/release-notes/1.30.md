## Version 1.30

- 新增“默认”“黑暗模式”“跟随系统”外观模式；跟随系统时会自动响应 Windows 应用颜色变化。
- 窗口在支持的 Windows 11 设备上请求系统亚克力背景，并提供 54%、70%、90% 三档透明度；两种外观共用同一档位。系统关闭透明效果或不支持时使用实色背景。
- 七类卡片采用与预览连成一体的分类标签；黑暗模式使用更深的卡片表面和柔和灰色选中框。
- 新增“前置粘贴项”，默认开启。通过 ClipNest 向目标应用发送粘贴快捷键后，所用历史卡片会移到“全部历史”第一位；关闭后沿用原排序，收藏板的手动顺序保持不变。
- 链接预览遇到 Google 或 Microsoft 登录跳转时，保留原链接站点，并尝试读取原站点图标，不再把登录页误当作目标页面。

既有加密记录和设置继续使用。自动网页预览仍只能读取无需登录即可访问的页面。
