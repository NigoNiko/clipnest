## 简体中文

### 新增内容

- 用一句话说明用户能使用的新功能。

### 调整内容

- 说明现有功能或界面发生的可感知变化。

### 性能提升

- 只在有可验证的实际改进时填写，说明用户会感受到的效果。

### Bug 修复

- 说明修复了什么问题，以及现在的表现。

发布时删除没有内容的分类，不写构建过程、内部实现、测试步骤或开发工具使用记录。

## 繁體中文

### 新增功能

- 簡短說明使用者可使用的新功能。

## English

### New

- Describe the feature in terms of what the user can now do.
