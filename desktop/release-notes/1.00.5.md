## 简体中文

### 新增

- 卡片栏支持随窗口后方内容变化的实时模糊背景。

### 调整与修复

- 保持原有圆角边缘，避免模糊层在四角露出。
- 优先使用可用的 GPU；实时模糊不可用时自动沿用原有背景效果。
- 实时模糊需要 .NET 8 Runtime（x64）。未安装时 ClipNest 仍可使用，并会提供官方下载入口。

## 繁體中文

### 新增

- 卡片列支援隨視窗後方內容變化的即時模糊背景。

### 調整與修復

- 維持原有圓角邊緣，避免模糊圖層在四角露出。
- 優先使用可用的 GPU；無法啟用即時模糊時，自動沿用原有背景效果。
- 即時模糊需要 .NET 8 Runtime（x64）。未安裝時 ClipNest 仍可使用，並會提供官方下載入口。

## English

### New

- The card shelf now supports a live blurred background that follows changes behind the window.

### Changes and Fixes

- Preserved the rounded window corners without exposing the blur layer at the edges.
- Uses available GPU acceleration first and keeps the previous background effect when live blur is unavailable.
- Live blur requires .NET 8 Runtime (x64). ClipNest remains usable without it and offers an official download link.
