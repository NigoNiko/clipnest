# ClipNest 1.00.3 for Windows

正式版从 `1.00.0` 开始，后续按三段版本号递增。此前的 `1.34.7` 为 Beta 测试版；设置页“关于”显示为“Version 1.00.3”。

ClipNest 是一个本地剪贴板工具。运行 `ClipNest.exe` 后，它会留在系统托盘中；默认按 **Ctrl + Alt + Q** 打开底部卡片栏，可在设置里修改。

## 使用

- 复制文字、Markdown、链接、代码、六位十六进制颜色、图片或文件，即可自动加入历史记录。
- Markdown 卡片保留原始源码。默认粘贴会同时提供 Markdown 源码、纯文本和排版后的 HTML，由目标应用选择其支持的格式；右键“粘贴 Markdown 源码”只提供原始文本。卡片预览窗口显示排版效果。
- Markdown 卡片在浅蓝灰色缩略框中显示原始内容；分类筛选菜单向上展开，避免贴近任务栏。
- 左键单击卡片可粘贴到先前的应用；在设置里关闭“直接粘贴”后，单击只会复制到剪贴板。
- “外观”可选择“默认”“黑暗模式”“跟随系统”三种外观模式。跟随系统会在 Windows 应用颜色变化后自动切换；新安装默认为跟随系统。
- “界面语言”可选择跟随系统、简体中文、繁体中文或 English；更改后立即更新界面，无需重启。
- “窗口透明度”有“透明”“默认”“不透明”三档，外观模式切换不会改变所选档位。卡片栏每次呼出时采集后方画面并柔化，配合圆角透明窗口显示玻璃效果；固定窗口期间，后方画面变化不会实时更新到模糊背景。
- “前置粘贴项”默认开启：成功粘贴历史记录后，它会回到“全部历史”的第一位；关闭后保持原先的时间排序。收藏夹的手动顺序不受影响。
- 右键卡片或预览内容可选择保留格式粘贴、无格式粘贴、编辑文字、重命名、添加到收藏夹、复制或删除。
- 用顶部搜索框和类型筛选查找内容。ClipNest 窗口处于活动状态时，Ctrl + 1 对应全部历史，Ctrl + 2～9、Ctrl + 0 对应从左到右的前九个收藏夹。更多收藏夹可在右键菜单中录入自定义快捷键。Alt + 1～9 可快速使用当前列表的前九项；同时按 Shift 可用纯文本粘贴。
- 打开卡片栏会选中当前列表的第一项；用左右方向键切换，按 Ctrl + F 再进入搜索框。
- 卡片固定高度，不产生垂直滚动。横向滚动条隐藏；可用鼠标滚轮或触控板水平滑动。左右方向键始终优先切换剪贴项目。
- 主窗口保留 Version 1.34.4 的底色、边框和阴影；设置窗口去除了发黑的外圈。卡片菜单和系统托盘右键菜单均采用圆角。顶部按钮用绿色表示“正在记录”，黄色表示“已暂停记录”，点击可切换状态。
- 搜索默认显示为圆形放大镜，同一个控件会展开为圆角搜索框；点击放大镜或窗口内搜索栏以外的位置会清除筛选并收起。在搜索栏内点击文字仍可继续编辑。顶部控件依次是搜索、固定、分类、记录状态和设置。类型按钮的文字避开右侧箭头，视觉居中。
- 顶部图钉可固定窗口：点击其他应用时窗口继续显示，选择剪贴项目后也保持打开；再次点击图钉或主动关闭窗口可取消固定。
- 在收藏夹中可拖动卡片调整顺序，位置会保存到数据库；搜索或分类筛选期间暂不拖动排序。
- “全部历史”和收藏夹标签采用圆角框，左侧保留指示点；它们与卡片的选中态使用一致的蓝色轮廓。收藏夹指示点从彩虹七色中选择，新建时随机分配，右键菜单可更换；它们不跟随全局主题色。顶部标签过多时可横向滚动，末尾保留“新建收藏夹”。
- 卡片在常见屏幕上的宽度为 188 逻辑像素，在有效逻辑宽度超过 2200、2800 像素的屏幕上适度加宽至 204、220 像素；高度为 168 像素。文本分类保留浅色标签，其余六类使用同色系、更深的半透明圆角标签；整张卡片共用一种底色，下方右侧以小字显示来源和时间。卡片表面由左上至右下有轻微明暗变化。图钉图形略微加长。
- 卡片栏底部不显示操作提示；完整操作与快捷键说明在“设置”页面。
- Ctrl + Shift + C 可暂停或恢复记录。托盘菜单也有相同操作。
- 卡片栏从任务栏下方滑出；点击窗口外、按 Esc 或再次按呼出快捷键会滑回并收起。
- 设置页分为“外观”“个性化”“数据与隐私”“关于”四类，并记住上次打开的分类。版本号显示在“关于”页。设置窗口采用与主窗口一致的圆角外观。开关项整行可点击，保存失败会恢复原状态并提示原因。保留时间、保存位置、呼出快捷键、直接粘贴、开机启动、备份和清空历史均可设置；“忽略指定应用”选项已移除。历史保留时间选框宽 106 像素。工具栏强调色及卡片选择框为蓝色；主题色选择器已移除。收藏夹内容不会因历史保留时间到期而删除。缩短保留期限时，会先显示即将删除的记录数并征求确认。
- 开机启动在当前用户登录 Windows 后让 ClipNest 驻留托盘，不主动弹出卡片栏；随时可在设置中关闭。移动程序文件夹后，请在设置中重新开启此选项，以更新启动路径。
- 来源程序显示为微信、Chrome 浏览器、Edge 浏览器等名称。WPS 表格和 Excel 复制单元格时优先保存文本，即使剪贴板同时提供图片预览；Qt 未识别文本时尝试读取 Windows 的 Unicode 文本格式。复制 Office 表格时会尽量保留 HTML 与 Windows 原生文本格式；实际粘贴效果取决于目标程序支持的格式。
- 文件卡片居中显示同一套折角文件图标：Excel、Word、PowerPoint、PDF、文本、压缩包、图片、音频、视频、文件夹和未知文件保留各类型的识别色；多文件保留数量标记。文本文件图标按原套件风格补齐，图片在高分辨率屏幕上保持清晰，预览区不再套白底或紫色边框。代码卡片采用黑白配色。
- 链接卡片优先显示手动命名，其次显示公开网页标题、剪贴板自带的链接文字和网站名称；图标优先使用网站声明的 favicon，也会尝试 Apple Touch 图标和站点根目录图标，失败时显示本地标识。图标填满卡片式圆角容器，透明部分露出同色系底色；长标题最多显示两行并以省略号结尾，过长网址保持单行省略。支持最多三次短链接跳转、手动重新获取预览，也可在右键菜单恢复自动网页标题；能处理部分网站不规范的字符编码。登录、动态页面或拒绝抓取的页面可能只显示网站名称。原始网址保持不变。

## 数据与隐私

默认保存在 `%LOCALAPPDATA%\ClipNest\clipnest.db`。从 1.25 起，剪贴记录、图片、链接预览和设置存入 SQLCipher 加密数据库；随机密钥保存在相邻的 `clipnest.db.key`，并由当前 Windows 账户的 DPAPI 保护。复制这两个文件到另一台电脑不能直接读取记录，日常使用不需输入密码。首次启动 1.25 时会在校验后把旧明文数据库转换为加密文件；转换失败时原数据库保留。若 Windows 账户或其保护密钥丢失，原密钥文件无法在另一台电脑恢复。旧版手动导出的明文备份不会自动加密，需自行妥善处理。

在设置中可查看并迁移数据库。迁移会先备份并校验新文件，成功后删除旧数据库和旧密钥；路径配置保留在 `%LOCALAPPDATA%\ClipNest\config.json`。设置页的新备份会同时生成加密 `.db` 和对应的 `.db.key` 文件；同一 Windows 账户恢复时两者都必须保留。历史记录不会同步。自动获取网页标题和图标默认开启，会直接访问复制链接及网页声明的图标地址，不使用第三方截图服务；可在设置中关闭。成功预览缓存七天，失败缓存一天。程序仍会尊重剪贴板声明的“不加入历史”标记。若要临时停止收集内容，请在主窗口或托盘菜单选择“暂停记录”；密码管理器复制的内容也可能被记录，请留意记录状态。

## 1.20 性能更新

- 水平列表只创建屏幕可见及附近的卡片，滚动、键盘选择和收藏夹拖动仍可访问列表中的其他项目；切换收藏夹时不再重建数百张卡片。
- 更换主题色时更新现有控件样式，不重新查询和创建剪贴卡片。短文本预览只读取所需部分，复制和粘贴仍从数据库读取完整内容；网页图标与图片数据只在卡片需要显示时读取。
- 安装包移除了当前界面不使用的 Qt PDF 渲染和虚拟键盘模块。原有文件类型图标、图片预览与链接预览继续保留。

## 安装与升级

运行 `ClipNest-1.00.3-Setup-x64.exe` 即可安装。默认位置是 `%LOCALAPPDATA%\Programs\ClipNest`，不需要管理员权限；若已有 ClipNest 开机启动项指向仍存在的旧程序，则默认沿用该安装目录，避免另外安装一份。安装过程会创建开始菜单的“ClipNest”和“卸载 ClipNest”快捷方式，并可选择创建桌面快捷方式；也可以从 Windows 的“已安装的应用”卸载。交互式卸载时会询问是否清除本地剪贴记录：选“是”会删除记录、同目录密钥、设置和更新缓存；选“否”保留记录、密钥及设置，供同一 Windows 账户重装后继续使用。静默卸载默认保留记录。升级或卸载时会清理旧测试版留下的 GitHub 访问令牌。自选数据目录只会删除 ClipNest 的文件，其余文件会保留。用户另外导出的备份不在卸载范围内。

首次从 1.20 及更早的便携版切换时，先从旧版托盘菜单选择“退出”，再运行安装程序。数据会自动沿用。安装目录内已确认的 1.20 旧程序文件会在升级时清理；安装目录之外的便携版文件夹不会被安装程序删除。若旧版已开启开机启动，安装程序会将该启动项指向新位置。

以后升级只需运行新版安装程序。安装程序会先让已安装版正常退出，清理已确认的旧程序文件，再在同一位置覆盖升级；完成后可以立即启动。无需手动解压或移动文件。历史记录和设置与安装目录分开保存。正式版保留数据库加密与 Qt 文件精简更新。`1.34.7` Beta 不能在线识别版本号较小的 `1.00.0`，测试版用户需要手动覆盖安装正式版一次；之后可正常在线更新。

## GitHub 更新

设置页新增“关于”，显示版本号、检查更新按钮和 GitHub 页面按钮。发现新版本时先弹出发布说明；点击“立即更新”后弹窗关闭，原“检查更新”按钮伸长为蓝色填充的下载进度，并直接显示百分比。程序读取 `NigoNiko/clipnest` 的最新 GitHub Release；有新版本时显示发布说明，并可忽略本次更新或立即更新。更新文件来自该 Release 的 Windows x64 安装包，下载后校验 GitHub 提供的 SHA-256 值，再运行安装程序更新原位置。临时安装包保存在 `%LOCALAPPDATA%\ClipNest\updates`，启动后自动清理；卸载时也会清理。

正式版只读取公开的 GitHub Release，检查和下载更新不需要访问令牌。

如需从源码构建，安装 Python 3.12、PySide6 6.9.2、PyInstaller 6.16.0 和 sqlcipher3 0.6.2，先用 `ClipNest.spec` 打包，再用 `ClipNest.iss` 和 Inno Setup 7 编译安装程序。`ClipNest.exe` 与 `_internal` 必须保持在同一文件夹中。

源代码在 `clipnest.py`，使用 Python 3.12 与 PySide6。程序只有本地依赖，未使用 Paste 的品牌、图标或素材。
