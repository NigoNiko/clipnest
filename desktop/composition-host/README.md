# ClipNest live blur host

This optional Windows process supplies a live acrylic background behind the Qt shelf. ClipNest keeps painting its own rounded surface and border. The host is inset so its native rounded edge cannot extend past the Qt edge.

Build with .NET 8 using the pinned Avalonia.Desktop 12.1.4 package. `build.ps1` uses an existing local package cache when available, otherwise the official NuGet feed. It publishes a framework-dependent Windows x64 host in `publish-framework` and marks it for inclusion by `ClipNest.spec` only after that publish succeeds. The target needs the **.NET 8 Runtime x64** (`Microsoft.NETCore.App`), which Windows does not guarantee to include. ClipNest checks for it before starting the host and offers the official download page if it is missing. For local testing, `CLIPNEST_BLUR_HOST` may point to any compatible build.

Avalonia tries ANGLE/Direct3D first, then software rendering. The host reports whether `ActualTransparencyLevel` is acrylic; ClipNest only disables the screenshot backdrop when acrylic is actually active. A failed host, unsupported acrylic, or missing runtime leaves the original screenshot backdrop in use. The real ClipNest shelf was exercised with isolated data at 100% and simulated 150% Qt scaling, with a moving striped background. The screenshot-backed fallback stopped when the live host became active, and the interior changed between captures. The framework-dependent host is about 27.5 MB unpacked, before installer compression. Testing on a clean Windows installation and on hardware with no usable GPU still remains before release. This is not part of a public release yet.
