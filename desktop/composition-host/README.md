# ClipNest live blur host

This optional Windows process supplies a live acrylic background behind the Qt shelf. ClipNest keeps painting its own rounded surface and border. The host uses the Qt window's exact physical bounds; its native corner radius is selected from the Qt screen scale so the blur remains inside the painted corner.

Build with .NET 8 using the pinned Avalonia.Desktop 12.1.4 package. `build.ps1` uses an existing local package cache when available, otherwise the official NuGet feed. It publishes a framework-dependent Windows x64 host in `publish-framework` and marks it for inclusion by `ClipNest.spec` only after that publish succeeds. The target needs the **.NET 8 Runtime x64** (`Microsoft.NETCore.App`), which Windows does not guarantee to include. ClipNest checks for it before starting the host and offers the official download page if it is missing. For local testing, `CLIPNEST_BLUR_HOST` may point to any compatible build.

Avalonia tries ANGLE/Direct3D first, then software rendering; this order does not verify hardware GPU use or select a particular adapter. The host reports whether `ActualTransparencyLevel` is acrylic; ClipNest only disables the screenshot backdrop when acrylic is actually active. A failed host, unsupported acrylic, or missing runtime leaves the original screenshot backdrop in use. The Qt shelf repositions the host when its Z-order changes so another topmost window does not appear between the two layers. On a display-scale change, the host restarts with a radius matched to the new scale. The real shelf was exercised with isolated data and a moving background, including a topmost window moved behind it in light and dark modes. Edge alignment was checked at 100%, 150%, and 200% scale. The framework-dependent host is about 27.5 MB unpacked, before installer compression. Clean Windows installations and hardware with no usable GPU have not yet been tested.
