# File preview icon sources

These PNGs are bundled locally for clipboard file preview. Microsoft Word, Excel, and PowerPoint product names and marks belong to Microsoft. Their icons identify the corresponding document formats within ClipNest; they do not represent ClipNest branding.

| Asset | Source |
| --- | --- |
| excel.png | https://commons.wikimedia.org/wiki/File:Microsoft_Office_Excel_(2025%E2%80%93present).svg |
| word.png | https://commons.wikimedia.org/wiki/File:Microsoft_Office_Word_(2025%E2%80%93present).svg |
| powerpoint.png | https://commons.wikimedia.org/wiki/File:Microsoft_Office_PowerPoint_(2025%E2%80%93present).svg |
| pdf.png | https://static2.sharepointonline.com/files/fabric/assets/item-types/256/pdf.png |
| text.png | https://static2.sharepointonline.com/files/fabric/assets/item-types/256/txt.png |
| archive.png | https://static2.sharepointonline.com/files/fabric/assets/item-types/256/zip.png |
| photo.png | https://static2.sharepointonline.com/files/fabric/assets/item-types/256/photo.png |
| generic.png | https://static2.sharepointonline.com/files/fabric/assets/item-types/256/genericfile.png |

The Office PNGs are Wikimedia-rendered thumbnails of Microsoft-authored 2025 icons. The remaining PNGs come from Microsoft's file-type icon CDN. All eight images were downloaded for Version 1.34.2; the app reads these local files at runtime and does not fetch them during card display.
