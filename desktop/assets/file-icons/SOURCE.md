# File preview icons

These PNGs were exported from the user-supplied `file-icons-seergb.zip` / `file-icons-seergb.sketch` source for ClipNest Version 1.34.2.

- Directly exported: `excel`, `word`, `powerpoint`, `pdf`, `archive`, `photo`, `generic`, `audio`, `video`, and `folder`.
- Matching addition: `text.png` uses the source Word document shape and line artwork with a slate gradient, to cover plain text, Markdown files, and log files.
- The original ZIP did not include a license file. Confirm redistribution rights before making this icon set part of a public release.

All PNGs are 300 × 360 pixels with transparency. The app scales them for the 150 × 100 pixel preview area and bundles them locally; card display makes no network request.
